# 01 — Executive Problem Framing

**Deliverable:** `01_problem_framing.docx` (or `.pdf`) in this folder.

Required content: executive question, SMART framing, MECE hypothesis structure,
executive KPI + supporting KPIs, scope, exclusions, assumptions, and the
decisions the analysis must enable.

## What gets marked

- Every KPI states **numerator, denominator, date basis, exclusion rules**. A KPI
  without all four is not a definition.
- The hypothesis structure is MECE **by construction**, not by assertion. Derive it
  from the KPI's own algebra: `contribution/txn = revenue/txn - cost/txn - risk/txn`,
  each splitting into *mix* vs *rate*.
- At least three competing hypotheses, each with the evidence that would
  **confirm** it and the evidence that would **reject** it. A hypothesis with no
  stated falsifier is an opinion.
- The data-trust hypothesis is a **gate**, not a branch — it is a precondition on
  evaluating the others, so it does not belong in the MECE split.
- "Decisions the analysis must enable" is the hook Task 8's action plan attaches
  to. Skipping it leaves the recommendations ungrounded.
